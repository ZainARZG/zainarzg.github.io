# Weather Prediction Model

Supervised learning project for next-day temperature and precipitation forecasting using long-range weather data from European cities.

## Overview

This project was built as part of my academic learning journey in Computer Engineering. It focuses on predicting next-day weather values using historical weather data and a supervised learning workflow.

## Role

## Problem

The goal of the project was to explore how historical weather patterns can be used to estimate next-day temperature and precipitation.

## Dataset

European cities weather dataset used for long-range historical weather records.

## Tech Stack

- Python
- Structured data analysis
- Supervised learning workflow

## Result

This project helped turn my early interest in machine learning into a working academic project and gave me practical experience with data-driven prediction.
