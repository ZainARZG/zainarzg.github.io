# Starter Repositories

This folder contains starter README files for projects that are already mentioned in the site content but do not yet have public GitHub repositories.

Current starter repos:

- `weather-prediction-basel`
- `ai-video-experiments`

Use them like this:

1. Create the repository on GitHub
2. Copy the matching README into that repo
3. Add your real code, screenshots, and instructions
4. Update the final repo link in [future-profile-data.yml](D:/Somethings/codex/ZAINARZG.github.io/future-profile-data.yml)
