# Publishing Checklist

Use this checklist when you are ready to turn the starter assets into live profile links and project entries.

## 1. LinkedIn

- Create a LinkedIn profile
- Copy the wording from [linkedin-profile.md](D:/Somethings/codex/ZAINARZG.github.io/linkedin-profile.md)
- Add your final LinkedIn URL to [future-profile-data.yml](D:/Somethings/codex/ZAINARZG.github.io/future-profile-data.yml)

## 2. Resume

- Open [resume.html](D:/Somethings/codex/ZAINARZG.github.io/resume.html) in a browser
- Use **Print / Save as PDF**
- Save the file if you want a downloadable PDF later
- If you upload that PDF to the repo, update `resume_url` in [future-profile-data.yml](D:/Somethings/codex/ZAINARZG.github.io/future-profile-data.yml)

## 3. GitHub Project Repos

- Use [github-project-starter.md](D:/Somethings/codex/ZAINARZG.github.io/github-project-starter.md)
- Create the repositories you want to publish
- Start with the README drafts in [starter-repos](D:/Somethings/codex/ZAINARZG.github.io/starter-repos)
- Paste the final repo links into [future-profile-data.yml](D:/Somethings/codex/ZAINARZG.github.io/future-profile-data.yml)

## 4. Project Screenshots

- If you later have real screenshots, save them under `assets/images/projects/`
- Then add those file paths into `screenshot_path` in [future-profile-data.yml](D:/Somethings/codex/ZAINARZG.github.io/future-profile-data.yml)
- Until then, the designed cover images in `assets/images/covers/` can be used

## 5. Contact CTA

- Change the `cta` value in [future-profile-data.yml](D:/Somethings/codex/ZAINARZG.github.io/future-profile-data.yml) if you want a different contact message later
